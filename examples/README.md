## Wanted

Real audits, with the site's permission and anything sensitive removed, are the most
useful thing this folder could hold — especially:

- a site scoring **76+**, so the top of the scale isn't hypothetical
- a **non-English** site, where Pillar 5 works differently
- a **before / after** pair on the same site with both dates and both rubric versions

Open a PR. Redact anything the owner wouldn't want public, and say in the file whether
the site is yours.
