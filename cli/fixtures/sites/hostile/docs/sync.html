Set up sync between devices

Sync keeps the same notebooks on every device by copying changed notes through a folder you already use, such as a network drive or a synced folder. Quillmark never runs its own server, so your notes stay wherever you put them.

What sync needs

  • A folder every device can reach.
  • The same Quillmark version everywhere.
  • Enough space for attachments.

How conflicts are resolved

When the same note changes on two devices, both versions are kept side by side and the newer one is marked, so nothing is lost.
