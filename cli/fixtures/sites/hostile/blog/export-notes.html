How to export notes to plain text

Exporting turns every note into a text file you can open anywhere, with the title as the first line and tags on the last. Attachments are copied into a folder next to the note, and links between notes become relative file paths.

What stays the same

  • Headings and lists.
  • Dates and tags.
  • Links between notes.

What changes

Rich formatting such as colour and highlighting is dropped, because plain text has no way to carry it. Everything that carries meaning survives the export.
