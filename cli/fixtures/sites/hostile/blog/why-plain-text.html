Why we store notes as plain text

Plain text outlives every application that edits it. A note written today in plain text will open in whatever editor exists in twenty years, which is not something any proprietary format can promise, and it can be searched and versioned with ordinary tools.

What we gave up

  • Embedded drawings.
  • Inline colour.
  • Rich tables.

What we kept

Structure, dates, tags and links all survive in plain text conventions that every editor understands.
