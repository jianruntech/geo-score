Alerts that reach the person on duty

An alert opens when a reading stays outside a room's limits for longer than the delay you set. It goes first to the person on the rota for that room by text message, then by phone call, and then to the next person if nobody acknowledges it within the escalation time you chose for the site.

How does an alert close?

An alert closes only when someone records what was done: the stock moved, the engineer called, or the door found open and shut again. That note becomes part of the record an inspector reads, beside the readings that opened the alert, so the site never has to reconstruct a night from memory.

Which alerts can be grouped?

Alerts from rooms that share a compressor can be grouped, so that one fault sends one alert rather than five. A sensor whose battery is low or whose radio link is weak opens a maintenance alert, which goes to the site manager during working hours and never wakes anyone at night.
