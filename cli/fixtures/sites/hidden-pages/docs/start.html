Getting started with Frostline

This guide takes a new site from an unopened box to its first alert. It assumes one gateway and up to forty sensors in the same building, which covers most kitchens, pharmacies and small warehouses. Larger sites follow the same steps for each building.

How do you place the gateway?

Mount the gateway near the middle of the area the sensors cover, at head height, away from metal shelving and from the compressors themselves. Connect it to power and to the network with the cable in the box, or insert the mobile data card if there is no network point nearby. The light turns green when it reaches the service.

How do you add a sensor?

Pull the tab out of the sensor to connect its battery, hold it near the gateway until both lights flash, and give it the name of the room it will live in. Then set the room's limits and the delay before an alert, as described in setting up rooms and alerts. The printable installation guide has the same steps with diagrams.
