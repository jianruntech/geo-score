Troubleshoot a corporate proxy

Behind a corporate proxy, external link checks can time out even though the links work in a browser. Set the proxy variables for the Tidemark process, or skip external hosts in the configuration and check them from a machine outside the proxy.

What to check first

  • The proxy variables.
  • The certificate bundle.
  • The skip list.

When to skip external checks

If the proxy cannot be changed, skip external hosts locally and run the full check in CI instead.
