Configure Tidemark

Tidemark reads one configuration file from the root of your site. The file sets which folder to crawl, which hosts to skip, how many requests to make at once and which problems should fail the build rather than only warn.

What you can set

  • The folder that holds the built site.
  • Hosts that are never checked.
  • Which problems fail the build.

How settings are resolved

Command-line flags win over the configuration file, and the configuration file wins over the defaults. Run with the explain flag to see which source supplied each value.
