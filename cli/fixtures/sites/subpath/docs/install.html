Install Tidemark

Tidemark ships as a single binary for macOS, Linux and Windows, and as a container image for build servers. Installing it takes one command, and the binary has no runtime dependencies, so it works the same on a laptop and in a pipeline.

Which package to use

  • Homebrew on macOS.
  • The release archive on Linux and Windows.
  • The container image in CI.

How to check the install

Run the version command. It prints the version and the path of the configuration file Tidemark will read, which is the first thing to check when a setting seems to be ignored.
