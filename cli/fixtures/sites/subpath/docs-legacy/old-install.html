Tidemark 1.x installation

Version one of Tidemark was distributed as a script that needed a separate runtime installed on the machine, together with a configuration file in the older format that listed every folder, every skipped host and every rule as separate top level keys, which is why the upgrade guide exists and why this page is kept only for teams that still run the old version on a build server that cannot be changed, and anyone starting today should use the current release instead, because the old script is no longer maintained, receives no security fixes and will stop working once the old runtime reaches the end of its support period later this year, after which these pages will be removed from the site entirely.
